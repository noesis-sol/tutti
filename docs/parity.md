# Parity with orchestra

The audit against the spec's parity matrix (`.orchestra/specs/tutti-spec.md`, Appendix A), which
1.0 needs (§ 14, § 1.1 Goal 1): for each row of the matrix, what tutti does, the modules that do it
and the tests that show it. *Kept* means as orchestra v0.7.7 has it; the other dispositions point to
the spec's section. Back to the [README](../README.md).

Audited on 2026-10-21 against `main` at 80e5c2b. Of the matrix's 83 rows, all 83 are as the spec
says: 51 *kept*, 27 *changed as specified* (new features among them) and 5 *dropped as specified*:

- **Missing** (0): compactions are counted and logged since tutti-4sa. The START block's `DEFERRED_FREE`
  lines are written since tutti-psr. The dispatch's footprint line is logged since tutti-d6q, the run's
  notifications are sent since tutti-sla, and the predictor runs in real runs since tutti-76k.
- **Differs** (0): the run lock's refusal names init, and § 9.2 says its files are emptied on
  release, since tutti-d5g. The wind-down line's narrow and empty forms are orchestra's since
  tutti-upv, the setup after a fix since tutti-ry9, a failed full check's last 40 lines reach the
  log, the reviewer and the report since tutti-zfj, and rechecks wait out holds and solo tickets,
  each in a slot, since tutti-t4y.

No row is marked *untested details* any more: the run loop's details, which tutti-b3k listed, and
those of startup, the interface and init, which tutti-178 listed, have their tests. Each follow-up
ticket says what to change. The week of real runs 1.0 also needs is the maintainer's.

`test/parity-doc.test.ts` checks this file against the spec and the code: a row per row of the
matrix, in its order; each with a disposition, and each gap with its ticket; and every module, test
file and test name given here is there.
